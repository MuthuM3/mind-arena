# Scene Specifications

This directory contains individual scene specifications for Today's Arena (TA-01 through TA-07), grounded in the approved interaction storyboards (`docs/frontend/todays-arena-storyboards.md`) and implementation packet (`docs/implementation/m1.5-slice-01-invitation-and-situation.md`).
