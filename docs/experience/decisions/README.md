# Experience Decision Records (EDRs)

This directory defines the Experience Decision Record (EDR) system for Mind Arena.

Per repository convention and `AGENTS.md`, durable experience and architectural decision records are maintained in [`docs/decisions/`](../../decisions/).

EDRs document visual, spatial, motion, content, pacing, interaction, and emotional design decisions that shape the user experience.

## Decision Record Template

```markdown
# EDR-XXX — Decision Name

## Status

Proposed | Accepted | Superseded

## Context

Describe the background, context, and motivation for this decision.

## User Problem

What specific user problem, confusion, or experience need does this decision address?

## Options Considered

1. **Option A:** Description, pros, and cons.
2. **Option B:** Description, pros, and cons.

## Decision

State the chosen experience direction clearly and concisely.

## Why

Explain the rationale behind choosing this direction over the alternatives.

## Evidence

Record user research findings, prototype testing feedback, or empirical observations supporting this decision.

## Tradeoffs

What trade-offs or compromises were accepted by choosing this path?

## What Would Make Us Reconsider

Define explicit conditions or negative evidence that would trigger a review of this decision.

## Related Scenes

List scene IDs affected by this decision (e.g., TA-01, TA-02).

## Related Architecture Decisions

List related ADRs or architectural contracts affected (e.g., ADR-0005).
```
